## Метки у каждой строки

| Метка | Что значит | Учить? |
|---|---|---|
| **ТВОЁ** | из твоего шаблона, не меняется | да |
| **ДА** | ты сказал «да» (16.11), корректор смотрит только язык | да |
| **СОВЕТ** | совет Claude, ты ещё не решил | нет, сначала корректор |

Всё, что помечено СОВЕТ и ВЫБОР, собрано во вкладке **«Решить с корректором»** под номерами К1–К84 (те же номера — в PDF).
Отмечаешь галочками, приложение показывает строку «Отмечено: К…», её скидываешь Claude — он собирает чистовик v1.0.

## Как обновить репозиторий

Загрузить с заменой: `index.html`, `fb_data.js`, `sw.js`, `README.md`.
`manifest.webmanifest` и три иконки не менялись (можно загрузить тоже — ничего не сломается).
Номер кэша в `sw.js` поднят до `forumsbeitrag-v0-2` — телефон сам заберёт новую версию при следующем открытии с интернетом.

Источник данных — `build_fb.py` (в проекте Claude: `claude/FB_v02_build.py`).
